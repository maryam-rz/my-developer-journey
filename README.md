## 🌸 06 — What I'm Learning from GitHub

<details>
<summary><b>🌱 Branches & Commits</b></summary>

Branches let me work on changes separately from the main branch. Commits record changes with messages that explain what I did.

</details>

<details>
<summary><b>💜 Pull Requests</b></summary>

Pull Requests let developers propose changes, discuss improvements, and review code before merging.

</details>

<details>
<summary><b>🧩 Issues & Collaboration</b></summary>

Issues help organize tasks, report bugs, and track ideas. Collaboration helps developers learn from different perspectives.

</details>

<details>
<summary><b>📚 Documentation</b></summary>

Good documentation explains what a project does, how to use it, and how others can contribute.

</details>
